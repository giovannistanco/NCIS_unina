This repository contains student projects from the **Networks and Cloud Infrastructures course** (NCIS), taught by Prof. Giorgio Ventre at the University of Napoli Federico II.

To submit the project work, students can use this repository: students need to create a [pull request](https://opensource.com/article/19/7/create-pull-request-github) and create a folder named using the last names of the group members, following the example: surname1_surname2_surname3_surname4. 
Only in cases where someone is completing the project alone, the student must use surname_firstname to avoid confusion among people with the same last name. 

**Notes and Recommendations**

When submitting source code, do not include binary files (.o) or executables (.exe).

All project files must be original. If you use third-party code, you must state it in the report and ensure that its license is open-source and non-proprietary.

For test files, avoid attaching documents (e.g., .pcap) that are too large. In such cases, it is better to provide a reference (URL) to these files rather than including them directly in the project folder.
